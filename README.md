# Stock Research Skill｜个股深度研究与投资前检查

面向 A 股、港股、美股的中文 AI 投研 skill。以中长期企业价值研究为主，将公司研究、反证、投资前检查和补充调查连成可跨对话接续的流程。

**研究 → 明确触发投资前检查 → 找到未知项 → 补充研究 → 再次检查与判断。**

## 能做什么

- 研究商业模式、竞争优势、财务质量、资本配置和情景估值。
- 从研究开始同步分析正向投资论点与失败路径，运用芒格倡导的逆向思考。
- 对成长依赖型公司的研究，引入费雪十五点的主题概述与取证方向。
- 在用户明确准备考虑投资时，逐项执行 213 题原创扩展检查清单。
- 保存证据、未知项、估值假设和历次判断，支持后续补查与新披露后的复查。

不按题目通过数量或总分机械决定投资。关键证据不足时保留未知状态。具体投资决定由使用者作出，skill 不执行交易。

## 安装

将本仓库中的 `.agents/skills/stock-research/` 完整复制到你的投研项目同名目录：

```text
你的投研项目/
└── .agents/skills/stock-research/
    ├── SKILL.md
    ├── agents/openai.yaml
    └── references/
```

例如，在终端运行以下命令后，把技能目录复制到目标项目。目标路径请替换成实际路径；若已有同名技能，先比较再更新。

```sh
git clone https://github.com/yifengingit/stock-research-skill.git
mkdir -p /path/to/your-project/.agents/skills
cp -R stock-research-skill/.agents/skills/stock-research /path/to/your-project/.agents/skills/
```

也可以直接把克隆后的仓库作为投研项目打开。使用支持 `SKILL.md` 的 AI 助手；平台未自动发现时，明确要求助手读取该文件。联网检索和本地文件读写由助手环境提供，本仓库不附带行情服务、API 密钥或独立执行程序。不同平台的发现机制可能不同。

## 使用示例

**开始研究：**

> 使用 $stock-research 深入研究腾讯控股（港股 00700），先完成公司研究，暂不进入正式检查清单。

**接续研究：**

> 继续研究腾讯，先读取现有档案，检查新披露，再补查最影响投资论点的未知项。

**进入正式检查：**

> 我准备考虑投资腾讯，开始正式的 213 题检查。无法回答的项目保留为待补证据。

**再次检查：**

> 根据最新财报更新研究和估值，复查受影响的项目，说明哪些判断改变了以及原因。

## 来源与适用边界

- **213 题是原创扩展版，不是帕伯莱原版、官方清单或授权译本。** 数量和方法背景的证据边界保留在原文件中；该文件按最初版本原样发布，其中“本次”“前次”指编写时的历史核实过程。
- 芒格逆向思考的相关段落核对自 Stripe Press 官方电子版；短语的雅可比归因按芒格文本记录，不声称独立考证其最早出处。
- 费雪十五点的书目与章节由 Wiley 官方目录确认；条目正文核对使用原书第三方转录，未逐页比对出版社授权全文。详情见研究框架文件。
- 中文主题概述、证据问题、记录格式与流程转化需相互区分；本项目执行规则不代表相关作者的原话或认可。
- 资料核对记录具有日期；今后开展个股研究应重新核实当前价格、披露和关键事实。本仓库不提供收益保证或个性化交易执行服务。

## 验证与迭代

当前已验证技能文件结构、参考文件链接、Q001—Q213 编号及题库完整性；尚未完成真实个股的端到端效果验证。欢迎通过 Issue 提供使用反馈，说明触发请求、预期行为和实际问题，并移除私人信息。

基础题库的修订应说明理由、版本变化和旧记录兼容方式。不要将新的框架直接累加为投资评分，也不要在缺少证据时把待查项改为已通过。
