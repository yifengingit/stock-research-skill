# Project rules

- Write user-facing research in Chinese unless the user asks for another language.
- Keep company research separate from the pre-investment checklist. Start the formal checklist only when the user asks for it.
- Keep the 213-question baseline unchanged unless the user approves a specific revision. Preserve question IDs and record the reason for each approved change.
- Separate source statements, project rules, estimates, and unknowns. Do not present project rules as an author's words.
- Read a source before using it as evidence. Record access limits and missing evidence.
- Do not use checklist scores to decide whether to invest.
- Do not publish company research, portfolio details, credentials, or private inputs with the skill.
- Keep edits focused on the requested change. Do not add investment frameworks without user approval.
- For skill edits, check the file format and local links. For baseline-preserving edits, compare the checklist before and after.

# Project facts

- This project supports individual-stock research in mainland China, Hong Kong, and the United States.
- The investment focus is long-term business value.
- The 213 questions are an original expansion inspired by Pabrai's method. They are not his official checklist.
- The user makes the investment decision. This project does not authorize trades or contact with third parties.
