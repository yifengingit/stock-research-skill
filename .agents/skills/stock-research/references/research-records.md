# 公司研究记录规范

## 路径与身份

在当前项目根目录使用 `research/<市场>-<证券代码>/`。市场标识为 `CN`、`HK`、`US`，保留代码前导零和必要股类标识。首次确认交易所、证券名称、股类、上市地、报价币种及报表币种。不同市场上市证券可共享企业事实，但价格、股数口径及股东权利分别核实，不混用。

公司档案在实际研究时建立；根据阶段创建需要的文件，不预先填充看似已研究的内容。

| 文件 | 职责 |
| --- | --- |
| research.md | 公司身份、研究状态、商业模式、竞争优势、财务与资本配置、反证、来源索引及下一步 |
| valuation.md | 价格时间、币种和单位、方法、数据输入、计算、三种情景、敏感性及限制 |
| checklist.md | 检查轮次、基础研究缺口、题库版本、Q001—Q213 逐项记录与复查范围 |
| open-questions.md | 未知项、优先级、证据需求、补查尝试、结果和重查条件 |
| decisions.md | 按轮追加的研究判断和决策记录；区分 AI 建议与用户实际决定 |

每份文件记录更新日期和资料截止日；重要历史判断通过 decisions.md 保留。使用用户时区，没有其他约定时用 Asia/Taipei。保留用户编辑和原始文件，仅更新本轮有证据支持的内容。

## research.md

开头记录：公司身份、研究阶段（研究中／基础研究具备／正式检查中／补查中／本轮检查已记录／已建议放弃）、最新披露期间、当前判断、关键缺口、下一步。阶段描述不表示风险已解决。

主体围绕商业模式、竞争优势、财务与资本配置组织，包含跨期和同行比较、最强反证和投资论点失效条件。财务比较注明报表口径、币种、单位、期间、重述及不可比因素；重点解释变化机制，不堆砌比率。

在主体中同步记录正向论点与失败路径：触发因素 → 经营/财务变化 → 每股价值或回报影响，并附支持证据、反证、未知项和失效条件。使用费雪视角时，按 [框架参考](investment-frameworks.md) 记录适用的 F 编号、当前判断和证据定位；成长依赖型公司逐项交代十五点，其他公司说明选用范围。已有段落可直接引用，避免另造重复报告。

来源用稳定编号，如 S001。每条包括标题、发布主体、URL 或项目内文件位置、发布日期、数据期间、访问日期、页码/章节/表格位置，以及支持的结论。访问失败或仅有搜索摘要的材料不得作为已读证据。原始披露和管理层主张的可信度需按内容判断，不能因出自公司就视为独立验证。

## valuation.md

至少记录：估值日及股价时间、交易所及股类、币种与单位、股数及稀释口径、主要输入来源、适用方法及理由、悲观/基准/乐观假设、计算过程、每股价值范围与敏感性。非交易日注明最近交易日价格，不称作实时价格。

根据方法解释利润或现金流正常化、再投资需求、净债务及优先索偿、股权价值换算。替代估值方法不适用的字段说明原因。标记缺失输入及其影响，不为了三种情景完整而捏造输入。提供可复核公式或计算步骤；计算规模需要时才另附模型文件。区别价值区间、价格条件和保证收益。

## checklist.md

开头记本轮编号、日期、使用的题库版本、研究基础是否具备、最新证据截止日和检查范围。正式检查覆盖全部基础题号；提前放弃或分阶段交付时保留剩余题号并标记未查，不暗示全数完成。

每题使用以下字段，可用结构化段落或易读表格，避免过宽表格：

- 题号与原题：保持原意和编号。
- 适用性及理由：适用／不适用；不适用解释业务或事实依据。
- 状态：未查／待补证据／风险可接受／重大风险／不适用。
- 当前回答：具体事实与机制，标明事实、推断、假设或用户自述。
- 证据：来源编号及页码/章节、数据期间；引用共享证据时指出支持哪个结论。
- 反证与未知项：与 open-questions.md 中的编号关联。
- 风险影响：触发条件、损失机制及对估值/投资论点/仓位讨论的影响。
- 下一步与复查条件：补查动作、日期或事件；本轮变化及理由。

状态含义：未查表示尚未研究；待补证据表示无法充分判断；风险可接受需明确依据、情景和接受条件；重大风险表示已有证据支持实质风险；不适用需业务理由。重大风险可与尚待补充的细节同时存在，在未知项栏继续记录。

完成标准分开表达：①题号覆盖完整；②每题已记录处理结果；③关键未知项是否仍阻碍决策。任何覆盖统计仅用于查漏，不是投资得分。

## open-questions.md

每项采用稳定编号 U001 等，记录：关联题号/论点、具体问题、重要性、是否阻碍买入建议、所需证据、已查来源和尝试结果、下一步、状态（待补／调查中／待外部信息／已解决）、解决证据与日期。第一阶段发现的问题可以先关联论点，正式检查时再补题号。

优先处理可能改变存续判断、财务可信度、股东权利或核心估值的事项。无法证实与已证伪分开。对关键问题必须取得足以支持判断的证据，不能以完成检索动作视为解决。

## decisions.md

每轮追加：时间与资料截止日、当前价格及其时间、AI 研究建议、核心论点与最强反证、估值范围及价格条件、五年后永久损失最可能的三条因果链、关键未知项、与上一轮相比改变了什么以及为什么、继续/放弃的条件、跟踪指标/来源/复查事件。

用户实际决定只有用户明确表达后才记录；否则写“用户尚未决定”。持仓比例、资金期限、杠杆、组合共同风险等个人信息缺失时记录待用户提供，不臆测数值。正式检查尚未开展时明确阶段，不能伪装为投资前最终审查结论。

## 题库版本变化

公司档案引用使用时的题库版本。修订获用户确认后记录变更日期、旧新题意和理由，保持既有编号的对应关系；新题使用新编号。既有决策记录仍注明当时版本，复查时明确迁移范围。
