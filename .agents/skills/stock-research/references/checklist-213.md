## 二、如何使用

1. 先理解企业并阅读原始披露，再逐项检查。清单的价值在于发现遗漏，不能替代研究。
2. 复选框只表示“已完成本项研究和记录”，不表示“企业通过”。每题另记：**未查／待补证据／风险可接受／重大风险／不适用**。
3. 对每个结论写下证据、日期、反证和影响。不适用也需说明原因；“没有找到”不等于“没有风险”。
4. 不按通过题数或平均分机械决策。财务真实性、生存能力或股东权益方面的一项重大问题，可能比许多优势更重要。
5. 压力情景需根据行业调整，不能把统一的利润降幅、债务倍数或估值折扣当作普适标准。银行、保险等行业尤需单独分析。
6. 首次完成后，保留适用的重点项目作为后续跟踪表；财报、融资、并购、治理或竞争发生重大变化时复查。

### A. 商业模式与能力圈

建议证据：年报业务分部、客户合同、收入构成与行业资料。以下问题均为原创扩展。

- [ ] **Q001** 我能否不用股价和行业口号，说明客户为什么付钱？
- [ ] **Q002** 实际使用者、付款者与采购决策者分别是谁，三者利益是否冲突？
- [ ] **Q003** 公司解决的是必须解决的问题，还是客户可以轻易推迟的需求？
- [ ] **Q004** 每项主要业务按什么单位收费，收入增长能否拆成数量与价格？
- [ ] **Q005** 总收入中哪些是经常性收入，哪些来自一次性项目？
- [ ] **Q006** 客户购买产品后还必须承担哪些额外成本，这会不会限制需求？
- [ ] **Q007** 公司在产业链中承担哪些风险，又凭什么取得目前的利润？
- [ ] **Q008** 我能否画出从采购、交付到回款的完整流程并找到资金占用点？
- [ ] **Q009** 核心利润是否来自主营业务之外、且难以持续的安排？
- [ ] **Q010** 业务是否复杂到我无法判断利润来自哪里、损失由谁承担？
- [ ] **Q011** 我是否读过至少一个完整经营周期的资料，而不只看最近的增长期？
- [ ] **Q012** 我对该行业的理解有哪些可验证的优势，哪些只是熟悉产品产生的自信？
- [ ] **Q013** 当前投资论点依赖哪些我无法独立验证的技术或商业判断？
- [ ] **Q014** 有没有重要业务、子公司或合约被我直接归入“其他”而未研究？
- [ ] **Q015** 什么新增信息会让我承认这家公司超出了我的能力圈？

### B. 债务结构与融资依赖

建议证据：债务附注、贷款协议、债券募集书、租赁和担保披露。以下问题均为原创扩展。

- [ ] **Q016** 把借款、债券、租赁及具有融资实质的安排合并后，公司承担多少固定偿付义务？
- [ ] **Q017** 未来各年度债务到期金额是否与可用现金及经营回款匹配？
- [ ] **Q018** 浮动利率负债占比是多少，利率上升会增加多少现金利息？
- [ ] **Q019** 外币债务与同币种收入是否匹配，汇率冲击是否会放大债务？
- [ ] **Q020** 哪些债务以核心资产抵押，违约时哪些经营能力会被拿走？
- [ ] **Q021** 债务有无追索权，风险能否从项目公司传导到母公司？
- [ ] **Q022** 贷款契约的关键指标是什么，按协议定义计算后还有多少余量？
- [ ] **Q023** 交叉违约或交叉加速到期条款会不会让局部问题扩散？
- [ ] **Q024** 评级下降是否会触发追加抵押、提高利率或提前偿还？
- [ ] **Q025** 公司披露的授信中，多少是已承诺且满足提款条件的额度？
- [ ] **Q026** 公司是否依赖短期融资支持长期、难变现的资产？
- [ ] **Q027** 控股股东的股权质押是否可能导致控制权或经营安排突变？
- [ ] **Q028** 关联企业担保是否可能把公司拖入本不属于它的债务危机？
- [ ] **Q029** 可转债、优先股或赎回承诺是否隐藏额外现金需求或稀释？
- [ ] **Q030** 公司是否必须持续借新还旧才能维持正常经营？

### C. 流动性与生存压力测试

建议证据：现金附注、现金流量表、营运资金明细与压力情景表。以下问题均为原创扩展。

- [ ] **Q031** 账面现金中有多少受限、质押或无法汇回，真正可动用多少？
- [ ] **Q032** 在收入下滑的情景中，公司每月净现金消耗会变成多少？
- [ ] **Q033** 若融资渠道关闭一段时间，现有流动性可以支持多久？
- [ ] **Q034** 若营业利润明显下降，现金利息及必要本金偿付能否覆盖？
- [ ] **Q035** 客户延迟付款时，现金缺口会在什么时候出现？
- [ ] **Q036** 供应商缩短账期或要求预付款时，公司是否仍能运转？
- [ ] **Q037** 存货必须降价出售时，回收现金是否足以覆盖相关付款？
- [ ] **Q038** 需求低谷时哪些支出确实可停，哪些只是管理层声称可停？
- [ ] **Q039** 公司是否把不可缺少的维护性资本支出当成可随时取消的投资？
- [ ] **Q040** 重大诉讼、退款或召回与经营低谷同时发生时，流动性够不够？
- [ ] **Q041** 出售资产的救急方案是否有真实买方、可行时间表及税费估计？
- [ ] **Q042** 所谓“母公司会支持”是否有可执行承诺及足够支持能力？
- [ ] **Q043** 若必须低价增发才能生存，现有股东会被稀释到什么程度？
- [ ] **Q044** 压力测试是否同时考虑销量、价格、成本和融资条件恶化的关联性？
- [ ] **Q045** 现金最紧张的月份是否早于我预计的经营恢复时间？

### D. 护城河的真实性

建议证据：同行经营数据、客户访谈、定价与续约记录。以下问题均为原创扩展。

- [ ] **Q046** 高利润究竟来自竞争优势，还是暂时的供不应求？
- [ ] **Q047** 竞争者复制产品、渠道或产能需要多少时间与资金？
- [ ] **Q048** 低成本地区的竞争者进入后，公司还能否维持合理利润？
- [ ] **Q049** 公司提价后是否留住客户，还是靠促销和返利掩盖流失？
- [ ] **Q050** 客户更换供应商的实际成本是什么，能否量化或找到案例？
- [ ] **Q051** 网络规模扩大是否真的提高用户价值，还是只有用户数量增长？
- [ ] **Q052** 客户能否同时使用多个平台，从而削弱所谓网络效应？
- [ ] **Q053** 规模优势是否体现为可持续单位成本差，而非单纯采购量大？
- [ ] **Q054** 品牌溢价是否由重复购买与价格差支持，而不只是知名度？
- [ ] **Q055** 专利、牌照或独家合同何时到期，到期后竞争格局会怎样？
- [ ] **Q056** 公司控制的是稀缺资源，还是可以通过新增投资快速扩大的供给？
- [ ] **Q057** 竞争优势的收益最终留在公司，还是被客户或供应商拿走？
- [ ] **Q058** 有没有竞争者在不增加亏损的情况下持续抢走份额？
- [ ] **Q059** 市场份额数据是否采用了对公司有利、但过窄的市场定义？

- [ ] **Q103** 资本支出预算是否经常超支，投产与盈利是否经常延迟？
- [ ] **Q104** 集团内部资本分配是否透明，少数股东是否分享实际收益？
- [ ] **Q105** 我的分析是否把总利润增长误当成每股价值增长？

### H. 会计质量与现金真实性

建议证据：审计报告、会计政策、收入确认与现金流附注。以下问题均为原创扩展。

- [ ] **Q106** 净利润与经营现金流长期不一致的具体原因是什么？
- [ ] **Q107** 收入是否在客户验收、付款或最终销售之前过早确认？
- [ ] **Q108** 应收账款增长是否明显快于收入，账龄是否恶化？
- [ ] **Q109** 坏账准备是否充分反映客户质量和实际回款变化？
- [ ] **Q110** 渠道库存是否增长过快，是否存在向经销商压货？
- [ ] **Q111** 存货计价与减值假设是否掩盖过时、滞销或价格下跌？
- [ ] **Q112** 公司是否把本应费用化的支出大量资本化？
- [ ] **Q113** 折旧年限、残值或摊销假设是否显著优于同行？
- [ ] **Q114** 非经常性收益占利润多少，所谓一次性费用是否年年发生？
- [ ] **Q115** 调整后利润是否剔除了维持业务所必需的真实成本？
- [ ] **Q116** 供应链融资、保理或应收出售是否美化经营现金流？
- [ ] **Q117** 客户预付款增加是否掩盖了未来交付义务和成本压力？
- [ ] **Q118** 收购形成的商誉是否依赖过于乐观的减值测试假设？
- [ ] **Q119** 审计意见、内控缺陷或报表重述是否触及核心财务可信度？
- [ ] **Q120** 我是否能将关键利润指标与法定报表及附注逐项对上？

### I. 增长质量与单位经济

建议证据：客户留存、分组收入、门店和产品经济模型。以下问题均为原创扩展。

- [ ] **Q121** 增长分别有多少来自有机扩张、收购、汇率及会计变化？
- [ ] **Q122** 新增客户或新门店在成熟后是否能产生正的贡献利润？
- [ ] **Q123** 获客成本是否包含折扣、销售人员及渠道分成等完整支出？
- [ ] **Q124** 客户终身价值是否基于足够长的留存数据，而不是乐观外推？
- [ ] **Q125** 获客投入多久回收，回收时间是否持续延长？
- [ ] **Q126** 留存率是否因统计窗口、客户分组或定义变化而虚增？
- [ ] **Q127** 收入增长是否集中于少数大客户或单一爆款？
- [ ] **Q128** 老客户支出增长来自真实使用增加，还是一次性提价？
- [ ] **Q129** 新市场的增长是否需要比原市场更多的营销和服务支出？
- [ ] **Q130** 促销停止后，销量和续费能否维持？
- [ ] **Q131** 新产品是否主要蚕食旧产品，而非增加整体利润？
- [ ] **Q132** 规模扩大后是否出现质量、交付或售后成本失控？
- [ ] **Q133** 增长所需营运资金和资本支出是否已进入预测模型？
- [ ] **Q134** 公司声称的潜在市场是否等于实际可服务、可盈利的市场？
- [ ] **Q135** 若增长放缓，商业模式能否转为稳定产出现金而非持续亏损？

### J. 周期、供应链与经营脆弱性

建议证据：跨周期价格与产能、供应合同、客户集中度、劳动安排。以下问题均为原创扩展。

- [ ] **Q136** 我是否把周期高点的利润当作常态利润估值？
- [ ] **Q137** 行业低谷的销量、价格与利润率历史上曾达到什么水平？
- [ ] **Q138** 当前需求是否被补库存、提前采购或补贴暂时抬高？
- [ ] **Q139** 行业扩产何时集中投放，是否会在需求减速时造成过剩？
- [ ] **Q140** 原材料涨价能否传导给客户，传导需要多久？
- [ ] **Q141** 长期采购承诺是否会在需求下降时留下多余库存或违约金？
- [ ] **Q142** 关键原料或零部件是否只有少数合格供应商？
- [ ] **Q143** 最大客户流失后，公司还有多少固定成本无法削减？
- [ ] **Q144** 某一工厂、仓库、港口或信息系统中断会影响多少业务？
- [ ] **Q145** 工会协议、养老金或劳动合同是否限制成本调整能力？
- [ ] **Q146** 熟练员工短缺或核心团队流失是否会限制交付？
- [ ] **Q147** 产品缺陷、召回和保修义务是否已有充分成本准备？
- [ ] **Q148** 保险覆盖是否真正对应主要风险，免赔和除外责任有多大？
- [ ] **Q149** 自然灾害及气候变化是否威胁关键资产或持续增加运营成本？
- [ ] **Q150** 管理层的复苏预测是否忽略行业退出缓慢和价格战持续的可能？

### K. 法律、监管与特殊行业风险

建议证据：适用司法辖区法规、诉讼文件、监管资本与行业披露。以下问题均为原创扩展。

- [ ] **Q151** 核心业务是否依赖可能被撤销、限制或不再续期的牌照？
- [ ] **Q152** 收入或利润是否高度依赖补贴、税收优惠及政府采购？
- [ ] **Q153** 反垄断、价格监管或平台规则变化会影响哪些利润来源？
- [ ] **Q154** 数据隐私、知识产权或内容授权是否存在重大未解决争议？
- [ ] **Q155** 产品对消费者的伤害是否可能导致赔偿、禁售或需求下降？
- [ ] **Q156** 环保修复、退役或场地清理义务是否充分计入负债？
- [ ] **Q157** 制裁、关税、出口限制或资本管制是否会切断核心业务？
- [ ] **Q158** 境外持股结构能否让普通股东实际取得经营资产的经济利益？
- [ ] **Q159** 诉讼的最坏结果是否影响公司存续，而不只是当期利润？
- [ ] **Q160** 若研究银行，其存款稳定性、资产期限和利率敏感性是否匹配？
- [ ] **Q161** 若研究贷款业务，贷款分批次违约及拨备是否反映真实信用损失？
- [ ] **Q162** 若研究保险，赔付准备金、再保险回收和承保纪律是否可靠？
- [ ] **Q163** 若研究房地产，项目现金流、预售义务和项目间资金调拨是否清楚？
- [ ] **Q164** 若研究资源企业，储量可采性、开采成本及许可证期限是否支持估值？
- [ ] **Q165** 若研究医药企业，临床证据、审批条件、专利期限和支付方定价风险是否纳入分析？

### L. 估值与安全边际

建议证据：自建估值、分部数据、稀释股本、情景与敏感性分析。以下问题均为原创扩展。

- [ ] **Q166** 估值所用利润是否扣除了周期、一次性收益和不合理会计假设？
- [ ] **Q167** 从企业价值转为股权价值时，是否正确处理净债务及其他优先索偿？
- [ ] **Q168** 股数是否包括期权、限制性股票、可转证券等潜在稀释？
- [ ] **Q169** 维护性资本支出与营运资金需求是否从可分配现金中扣除？
- [ ] **Q170** 估值中增长、利润率、再投资率与资本回报率是否彼此一致？
- [ ] **Q171** 终值占总价值多少，结论是否主要依赖遥远年份的假设？
- [ ] **Q172** 永续增长与折现率是否匹配币种、通胀和业务风险？
- [ ] **Q173** 当前股价隐含多高增长和利润率，这些条件是否现实？
- [ ] **Q174** 可比公司是否具有相近业务、杠杆、周期位置及会计口径？
- [ ] **Q175** 分部估值是否重复计算内部交易、现金或交叉持股？
- [ ] **Q176** 资产价值是否扣除了处置成本、税费和债权人的优先受偿？
- [ ] **Q177** 悲观情景下股东价值是多少，永久损失来自哪些具体机制？
- [ ] **Q178** 安全边际是否能覆盖主要估计误差，而不仅仅是低于我的目标价？
- [ ] **Q179** 预期收益中有多少来自经营现金回报，有多少依赖估值倍数上升？
- [ ] **Q180** 若价值实现比预期晚几年，税费后的年化收益是否仍有吸引力？

### M. 证据质量与认知偏差

建议证据：研究日志、原始披露、反方材料与历史决策记录。以下问题均为原创扩展。

- [ ] **Q181** 关键结论是否有原始材料支持，还是来自反复转载的同一个说法？
- [ ] **Q182** 我是否主动寻找过能够推翻投资论点的最强证据？
- [ ] **Q183** 反方最有力的论点是什么，我的回应是否有事实支持？
- [ ] **Q184** 名人持仓是否替代了自己的研究，且我是否知道披露的滞后性？
- [ ] **Q185** 熟悉品牌、喜欢产品或认同创始人是否影响了风险判断？
- [ ] **Q186** 买入成本或历史高点是否成为估值锚点？
- [ ] **Q187** 我是否因为投入了大量研究时间而不愿放弃这个标的？
- [ ] **Q188** 近期股价上涨是否让我反过来提高了对经营质量的评价？
- [ ] **Q189** 我是否只研究成功公司，忽略相似条件下失败的样本？
- [ ] **Q190** 管理层、卖方或行业专家是否存在影响其陈述的利益关系？
- [ ] **Q191** 我是否把资料未披露或暂时没有坏消息当成风险不存在？
- [ ] **Q192** 模型是否通过精确小数掩盖了关键输入的高度不确定性？
- [ ] **Q193** 我是否对利好和利空采用了不同的证据标准？
- [ ] **Q194** 当前情绪、疲劳或外部压力是否降低了独立判断能力？
- [ ] **Q195** 如果从未持有这只股票，我今天是否仍会接受同样的投资论证？

### N. 仓位、跟踪与退出纪律

建议证据：个人资金安排、组合风险表、监控指标与决策日志。以下问题均为原创扩展。

- [ ] **Q196** 这笔投资的资金使用期限是否长于价值实现所需时间？
- [ ] **Q197** 我是否使用了可能因股价下跌而被迫平仓的借款或衍生工具？
- [ ] **Q198** 单一公司永久损失对整体资产的影响是否在可承受范围内？
- [ ] **Q199** 多个持仓是否实际暴露于同一利率、商品、客户或政策风险？
- [ ] **Q200** 交易流动性是否足以让我在合理时间内调整仓位？
- [ ] **Q201** 仓位大小是否反映了不确定性和下行损失，而非情绪确信？
- [ ] **Q202** 加仓前是否重新检查了基本面，而不只是看到价格更低？
- [ ] **Q203** 我是否写下了可观察、可验证的投资论点失效条件？
- [ ] **Q204** 每个关键假设是否对应跟踪指标、数据来源和复查时间？
- [ ] **Q205** 出现融资、治理或会计重大变化时，是否会立即重新评估？
- [ ] **Q206** 卖出理由是否区分了价值受损、估值过高及资金用途变化？
- [ ] **Q207** 我是否因为短期获利就卖出，而没有重新判断未来价值？
- [ ] **Q208** 替换持仓的收益优势是否足以覆盖税费、交易成本和判断误差？
- [ ] **Q209** 复盘是否分别评价决策过程与结果，避免把运气当成能力？
- [ ] **Q210** 新的失败教训是否已转为具体检查问题，并删除重复或无用条目？

### O. 最终决策记录

建议证据：以上研究的书面归纳。以下问题均为原创扩展。

- [ ] **Q211** 假设五年后发生永久性资本损失，最可能的三条因果链是什么，现有证据如何支持或反驳它们？
- [ ] **Q212** 尚未解决的关键未知项有哪些，哪些必须先补证据，哪些可以通过价格或仓位承担？
- [ ] **Q213** 综合当前价格、保守价值、失败路径和机会成本，我的决定是买入、继续观察还是放弃，理由及重审条件分别是什么？
